# Update Docs
This skill helps you update documentation for your projects or skills.
## When to Use This Skill
Use this skill when the user:
- Asks for help with writing or updating documentation
- Wants to generate a README file for a project or skill
- Needs to create documentation for new features or updates
- Expresses interest in improving the clarity or completeness of their docs
## How to Help Users Update Docs
### Step 1: Understand Their Documentation Needs
When a user asks for help with documentation, identify:
1. The type of documentation they need (e.g., README, API docs, user guides)
2. The specific content they want to include (e.g., installation instructions, usage examples, API references)
3. The format they prefer (e.g., Markdown, HTML)
### Step 2: Generate or Update Documentation
 Create docs for stages in folder `docs/ai`, each folder should have a feature docs follow their folder name as a stage process request.
 Naming convention for docs should be `feature-{feature name}.md` and should example: Update README for a project with new features → `docs/ai/design|implementation|monitoring|planning|requirements|testing/feature-new-features.md`
### Step 3: Provide Guidance on Best Practices
You can also offer guidance on best practices for writing clear and effective documentation, such as:
- Using concise and descriptive language
- Organizing content with headings and sections
- Keeping documentation up to date with project changes
By following these steps, you can assist users in creating and maintaining high-quality documentation for their projects or skills.
